# Video Testimony

A responsive gallery of developer journey videos. Each card includes a YouTube thumbnail, creator, summary, and duration.

## Live demo

Not deployed yet. The GitHub Pages URL is expected to be:
`https://sohamm-afk.github.io/Video_Testimony/`

## Features

- Six developer story videos with factual summaries
- Privacy-enhanced YouTube embeds loaded when a card is opened
- Modal navigation, keyboard controls, and focus restoration
- Responsive three-, two-, and one-column layouts

## Files

- `index.html` — page structure
- `style.css` — layout and responsive styles
- `script.js` — video data and interactions
